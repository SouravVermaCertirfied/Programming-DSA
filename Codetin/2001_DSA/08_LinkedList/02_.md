# Linked List Interview Cheat Sheet (Qualcomm / Top Tech Interviews)

The goal in most linked-list problems is recognizing **which pattern applies**. If you master the patterns below, you'll solve the majority of linked-list interview questions.

---

# 1. Basic Node Template

```cpp
struct ListNode {
    int val;
    ListNode* next;

    ListNode(int x) {
        val = x;
        next = nullptr;
    }
};
```

---

# 2. Universal Traversal Pattern

```cpp
ListNode* curr = head;

while (curr) {
    // process curr
    curr = curr->next;
}
```

Time: O(n)

Space: O(1)

---

# 3. Dummy Node Pattern ⭐⭐⭐⭐⭐

Most important pattern.

Use when:

- Delete node
- Insert node
- Merge lists
- Remove duplicates
- Partition list

Instead of treating head separately.

```cpp
ListNode dummy(0);
dummy.next = head;

ListNode* prev = &dummy;
ListNode* curr = head;
```

Example:

```cpp
return dummy.next;
```

Common interview questions:

- Remove Nth Node From End
- Merge Two Lists
- Partition List
- Delete Duplicates

---

# 4. Fast & Slow Pointer Pattern ⭐⭐⭐⭐⭐

Most frequently asked pattern.

```cpp
ListNode* slow = head;
ListNode* fast = head;

while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;
}
```

---

## Applications

### A. Find Middle

```cpp
while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;
}

return slow;
```

Questions:

- Middle of Linked List
- Reorder List

---

### B. Detect Cycle

```cpp
while (fast && fast->next) {
    slow = slow->next;
    fast = fast->next->next;

    if (slow == fast)
        return true;
}
```

Questions:

- Linked List Cycle

---

### C. Find Cycle Start

After collision:

```cpp
ListNode* p1 = head;
ListNode* p2 = slow;

while (p1 != p2) {
    p1 = p1->next;
    p2 = p2->next;
}

return p1;
```

Question:

- Linked List Cycle II

---

# 5. Reverse Linked List Pattern ⭐⭐⭐⭐⭐

Absolute must know.

```cpp
ListNode* prev = nullptr;
ListNode* curr = head;

while (curr) {
    ListNode* nextNode = curr->next;

    curr->next = prev;

    prev = curr;
    curr = nextNode;
}

return prev;
```

Visual:

```
prev <- curr -> next
```

Questions:

- Reverse Linked List
- Reverse Between
- Reverse K Group
- Palindrome List
- Reorder List

---

# 6. Reverse Between Positions

Pattern:

```cpp
dummy -> 1 -> 2 -> 3 -> 4 -> 5

left = 2
right = 4
```

Steps:

1. Reach node before left
2. Reverse sublist
3. Reconnect

Questions:

- Reverse Linked List II

---

# 7. K-Group Reversal Pattern ⭐⭐⭐⭐

Questions:

- Reverse Nodes in K Group

Framework:

```cpp
1. Find kth node
2. Reverse k nodes
3. Connect previous part
4. Repeat
```

Template idea:

```cpp
while (true) {

    kth = getKth(...);

    if (!kth)
        break;

    reverse current block;
}
```

---

# 8. Merge Two Sorted Lists Pattern ⭐⭐⭐⭐⭐

```cpp
ListNode dummy(0);

ListNode* tail = &dummy;

while (l1 && l2) {

    if (l1->val < l2->val) {
        tail->next = l1;
        l1 = l1->next;
    } else {
        tail->next = l2;
        l2 = l2->next;
    }

    tail = tail->next;
}

tail->next = l1 ? l1 : l2;

return dummy.next;
```

Questions:

- Merge Two Sorted Lists
- Merge K Lists (building block)

---

# 9. Merge K Sorted Lists

### Approach 1: Min Heap ⭐⭐⭐⭐

```cpp
priority_queue<
    ListNode*,
    vector<ListNode*>,
    cmp
> pq;
```

Complexity:

```
O(N log K)
```

Questions:

- Merge K Sorted Lists

# 10. Two-Pointer Gap Pattern ⭐⭐⭐⭐⭐

Create fixed gap between pointers.

Example:

Remove Nth Node From End.

```cpp
fast = head;
slow = head;

Move fast n steps

while (fast->next) {
    fast = fast->next;
    slow = slow->next;
}
```

Questions:

- Remove Nth Node
- Find Kth From End

---

# 11. Delete Node Pattern

Delete current node when previous known.

```cpp
prev->next = curr->next;
delete curr;
```

Questions:

- Delete Node
- Remove Elements

---

# 12. Delete Node Without Previous Pointer ⭐⭐⭐⭐

Classic trick.

```cpp
node->val = node->next->val;
node->next = node->next->next;
```

Question:

- Delete Node in Linked List

---

# 13. Partition List Pattern ⭐⭐⭐⭐

Create two lists.

```cpp
smallDummy
largeDummy
```

```cpp
if (curr->val < x)
    small list
else
    large list
```

Finally:

```cpp
smallTail->next = largeDummy.next;
```

Question:

- Partition List

---

# 14. Palindrome Linked List Pattern ⭐⭐⭐⭐⭐

Very popular.

Steps:

### 1. Find middle

```cpp
slow fast
```

### 2. Reverse second half

```cpp
reverse(slow)
```

### 3. Compare

```cpp
while (second) {

    if (first->val != second->val)
        return false;

    first = first->next;
    second = second->next;
}
```

Question:

- Palindrome Linked List

Complexity:

```
O(n)
O(1)
```

# 15. Reorder List Pattern ⭐⭐⭐⭐⭐

Input:

```
1→2→3→4→5
```

Output:

```
1→5→2→4→3
```

Recipe:

### Step 1

Find middle

### Step 2

Reverse second half

### Step 3

Merge alternately

```cpp
first second

first->next = second
second->next = firstNext
```

Question:

- Reorder List

---

# 16. Intersection of Two Lists ⭐⭐⭐⭐

Elegant trick.

```cpp
ListNode* p1 = headA;
ListNode* p2 = headB;

while (p1 != p2) {

    p1 = p1 ? p1->next : headB;
    p2 = p2 ? p2->next : headA;
}

return p1;
```

Why works:

Both traverse:

```
A + B
B + A
```

Question:

- Intersection of Two Linked Lists

---

# 17. Clone Random Pointer List ⭐⭐⭐⭐⭐

Hard favorite.

Node:

```cpp
next
random
```

### O(1) Space Trick

Pass 1:

```cpp
A -> A'
B -> B'
```

Insert cloned nodes.

Pass 2:

```cpp
A'.random = A.random->next
```

Pass 3:

Separate lists.

Question:

- Copy List with Random Pointer

---

# 18. Circular Linked List Pattern

Cycle:

```cpp
tail->next = head
```

Always avoid infinite loops.

Instead of:

```cpp
while (curr)
```

Use:

```cpp
do {
   ...
} while(curr != start);
```

or count nodes.

Questions:

- Circular List Insertions
- Cycle Detection

---

# 19. Recursive Linked List Pattern ⭐⭐⭐

Useful for:

- Reverse List
- Merge Lists

Reverse recursively:

```cpp
ListNode* reverse(ListNode* head) {

    if (!head || !head->next)
        return head;

    ListNode* newHead =
        reverse(head->next);

    head->next->next = head;
    head->next = nullptr;

    return newHead;
}
```

---

# 20. Important Edge Cases Checklist ⭐⭐⭐⭐⭐

Always ask:

### Empty List

```cpp
head == nullptr
```

### Single Node

```cpp
head->next == nullptr
```

### Two Nodes

Many reorder/reverse bugs occur here.

### Delete Head

Use dummy node.

### Even/Odd Length

Middle calculation differs.

### Cycle Exists

Traversal may never stop.
