# A Good Mental Workflow During solving

When given a linked-list problem:

1. Draw the list.
2. Identify the pattern:
    - Delete/insert → Dummy node
    - Middle/cycle → Fast & slow
    - Reverse → 3 pointers
    - Kth from end → Gap pointers
    - Sorted merge → Dummy + tail
3. Walk through a small example by hand.
4. Code.
5. Dry-run on:
    
    Empty list - One node - Two nodes - Even length - Odd length - Head deletion - Tail deletion. 
    
6. Think of time compleixy, space complexity, can i do it with/without recursion ?

# The Three Linked List Templates to Memorize in C

### Template 1: Dummy Node

```c
ListNode dummy;
dummy.next = head;

ListNode* prev = &dummy;
ListNode* curr = head;

return dummy.next;
```

---

### Template 2: Fast & Slow

```c
ListNode* slow = head;
ListNode* fast = head;

while (fast && fast->next)
{
    slow = slow->next;
    fast = fast->next->next;
}
```

Used for:

- middle node
- cycle detection
- palindrome
- reorder list

---

### Template 3: Reverse List

```c
ListNode* prev = NULL;
ListNode* curr = head;

while (curr)
{
    ListNode* next = curr->next;

    curr->next = prev;

    prev = curr;
    curr = next;
}

return prev;
```

Used for:

- reverse list
- palindrome
- reorder list
- reverse k-group
- reverse between

### Template 4: Merge Two Sorted Lists

```c
ListNode dummy;
dummy.next = NULL;

ListNode* tail = &dummy;
```

# Exmaples : 
## Example 1: Remove All Nodes With Value x

Input:

```
6 -> 1 -> 6 -> 2 -> 6
```

Remove all `6`s.

```c
ListNode* removeElements(ListNode* head, int x)
{
    ListNode dummy;
    dummy.next = head;

    ListNode* prev = &dummy;
    ListNode* curr = head;

    while (curr)
    {
        if (curr->val == x)
        {
            prev->next = curr->next;
        }
        else
        {
            prev = curr;
        }

        curr = curr->next;
    }

    return dummy.next;
}
```

Notice:

```c
prev = &dummy;
```

This is the key idea.

The dummy acts as the predecessor of the head.

---

## Example 2: Delete First Node

Without dummy:

```c
if (head && head->val == target)
{
    head = head->next;
}
```

Special case.

With dummy:

```c
dummy -> head
```

Then deletion is always:

```c
prev->next = curr->next;
```

No special handling.

## Example 3: Remove Nth Node From End

This is a Qualcomm-style favorite.

```c
ListNode* removeNthFromEnd(ListNode* head, int n)
{
    ListNode dummy;
    dummy.next = head;

    ListNode* fast = &dummy;
    ListNode* slow = &dummy;

    for (int i = 0; i <= n; i++)
        fast = fast->next;

    while (fast)
    {
        fast = fast->next;
        slow = slow->next;
    }

    slow->next = slow->next->next;

    return dummy.next;
}
```

Why start from dummy?

Because removing the first node must still work.

Example:

```
1 -> 2 -> 3
```

Remove 3rd from end.

Result:

```
2 -> 3
```

Dummy makes it automatic.

## Example 4: Merge Two Sorted Lists

This pattern appears constantly.

```c
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2)
{
    ListNode dummy;
    ListNode* tail = &dummy;

    dummy.next = NULL;

    while (l1 && l2)
    {
        if (l1->val < l2->val)
        {
            tail->next = l1;
            l1 = l1->next;
        }
        else
        {
            tail->next = l2;
            l2 = l2->next;
        }

        tail = tail->next;
    }

    tail->next = l1 ? l1 : l2;

    return dummy.next;
}
```
