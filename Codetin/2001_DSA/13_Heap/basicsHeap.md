# Heap
- complete binary tree.
- represented in form of an array.
- the first index is considered as the root node.

>left idx       = 2i + 1  
>right idx      = 2i + 2  
>parnent idx    = (i-1)/2  



**Minheap** - Every node has its value lesser than its decendants.
**Maxheap** - Every node has its value greater than its decendants.
